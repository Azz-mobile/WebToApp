Dokumentasi Azz Web2App

            
Panduan lengkap mengubah website menjadi aplikasi Android WebView siap rilis menggunakan Azz Web2App.


            
1. Alur Kerja Pembuatan Aplikasi

            
    
              
  1. Buka menu Create New App dan masukkan URL website (wajib menggunakan HTTPS untuk keamanan Android 9+).
    2. 
              
  2. Atur Nama Aplikasi, Package Name unik (misalnya com.tokosaya.app), dan unggah logo beresolusi tinggi (disarankan 512x512 px).
    3. 
              
  3. Sesuaikan warna tema, status bar, splash screen, serta izin seperti kamera, upload file, dan tombol kembali.
    4. 
              
  4. Uji tampilan melalui Live App Preview di sisi kanan layar.
    5. 
              
  5. Buka menu Build APK & Export untuk menghasilkan kode sumber Android Studio.
    6. 
            


            
2. Cara Kompilasi Source Menjadi File .APK

            
Setelah mengunduh paket source code dari halaman Build:

            
    
              
  1. Buat proyek baru di Android Studio dengan template Empty Views Activity (Java) menggunakan Package Name yang sama.
    2. 
              
  2. Ganti isi file AndroidManifest.xml, MainActivity.java, build.gradle, dan strings.xml dengan kode yang dihasilkan oleh Azz Web2App.
    3. 
              
  3. Klik menu Build → Build Bundle(s) / APK(s) → Build APK(s) di Android Studio.
    4. 
              
  4. File app-debug.apk atau app-release.apk siap dipasang di perangkat Android.
    5.
